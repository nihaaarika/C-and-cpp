## ▶️ How to Run the Programs

1. Install a C/C++ compiler, such as GCC or G++.
2. Clone this repository:

   ```bash
   git clone https://github.com/nihaaarika/C_LANGUAGE.git
   ```

3. Navigate to the repository folder:

   ```bash
   cd C_LANGUAGE
   ```

4. Compile and run a C program:

   ```bash
   gcc C/1_program.c -o program
   ./program
   ```

5. Compile and run a C++ program:

   ```bash
   g++ C++/1_program.cpp -o program
   ./program
   ```

*Note: On Windows, run the generated executable using `.\program.exe` in PowerShell.*
